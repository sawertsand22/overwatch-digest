# Overwatch digest

Запусти сборщик из корня проекта и покажи результат в чате.

## Шаги

1. Выполни в корне проекта:

   ```bash
   python run.py --no-publish
   ```

   На Debian — `python3 run.py --no-publish`. Скрипт не трогает GitHub Issue,
   только обновляет `digests/latest.md` и `digests/latest.html`.

2. Прочитай `digests/latest.md`.

3. Покажи пользователю выжимку на русском:
   - сначала блок **🆕 Герои**, если он непустой — это самое важное;
   - затем **🎨 Скины и косметика**;
   - затем остальное, по 1 строке на материал: заголовок-ссылка + короткая
     суть своими словами (не копируй описание целиком);
   - местные картинки покажи как `![alt](путь)` — путь уже относительный
     к `digests/`, при необходимости поправь на `../images/...`.
   - в конце — упомяни источники, которые не ответили, если такие были.

4. Если новых материалов нет (`новых материалов: 0`), так и скажи одной
   строкой и предложи открыть `digests/latest.html` с прошлым срезом.

## Чего не делать

- Не публикуй в GitHub Issue без явной просьбы — для этого есть Actions.
- Не пересказывай весь файл дословно: цель — чтобы пользователь за 10 секунд
  понял, что нового в игре.
